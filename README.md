Entry for the [make.fun bounty "Deadpan Forecasts for Cities That Do Not Exist"](https://make.fun/c/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c) ($2, winner takes all). One original line of weather for a city that does not exist, delivered completely deadpan.

## The line

> In Glimmerwick today: overcast with a chance of Tuesdays; carry an umbrella and low expectations.

97 characters, one line.

## Run it

```sh
node index.js
```

`index.js` reads `line.txt`, prints the forecast, and verifies it is a single line within the 140-character cap.
